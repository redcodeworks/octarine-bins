# Developer package list of the octarine-os dx image: carried by ghcr.io/redcodeworks/octarine-bins-dx as /packages/dev.txt
# (moved here from octarine-images' dev-packages on 2026-11-16).
# Installed by install.sh (same directory): one strict `dnf5 install`, a package that cannot be
# installed fails the build.
#
# SYNTAX: one entry per line; blank lines and #-comments are ignored.
#   name         a package
#   @group-id    a package group (dnf5 accepts @id as an install argument)
#   a|b|c        ALTERNATIVES for one package whose name differs between Fedora releases: the first
#                alternative that exists in the enabled repositories is installed (newest name
#                first); if none exists the build fails.
# Consumers can drop entries with EXCLUDE="name1 name2" (see dx/README.md).
#
# Official Fedora packages only.
#
# NOTES:
# - Names that differ between Fedora releases use alternatives (the dx image is Fedora 45 today; the old names stay
#   as the second alternative so a release change does not break the install).
# - Do NOT add ffmpeg-free-devel: libGLU cannot install once Fedora's mesa is excluded in favour of another Mesa.
