# octarine-bins-gx

The inputs of the gx (gaming) image of octarine-os: the gaming package lists and their installers, plus (later) any prebuilt binary only gx needs.

- `packages/required-fedora.txt`, `required-negativo17.txt` (Steam), `required-copr.txt` (Sunshine, exact version and release): strict, installed in that order. `packages/optional-fedora.txt` (overlays, input helpers, diagnostics, Proton helpers): best effort. Moved here from octarine-images on 2026-11-16. Syntax and policy: `CLAUDE.md`, "The package lists".
- In the image: those files and `/packages/install.sh` (the shared copy in `installer/`). `bash /packages/install.sh` runs the whole sequence, with the negativo17 repository enabled for its own call only.
- What the lists assume of the consuming image: Mesa for x86_64 and i686 is available (Fedora and negativo17 ship both); the negativo17 repository `fedora-multimedia` is configured (the Universal Blue base ships it); `dnf5-plugins` is installed for the COPR list. `steam` comes from negativo17 (`steam-1.0.0.87-4.fc45` on 2026-11-16), which is newer than Fedora for Steam's own dependencies, so installing `required-negativo17.txt` also brings about 60 packages from negativo17 instead of Fedora (Mesa for both architectures, `libva`, the codec libraries, `gstreamer1-plugins-bad` and similar; dnf5 dry run on Fedora 45, 2026-11-16, with only Steam requested). `required-fedora.txt` is installed first by the installer; check `dnf5 repoquery --installed --queryformat '%{name} %{from_repo}\n'` if the origin matters.
- No binary component yet: `/COMPONENTS` is empty and there is no component directory.

To add a binary component `<name>`: copy a stage of `src/Containerfile` into `gx/Containerfile` (above the assemble stage, plus a `COPY --from=<name> /out /out/<name>` line there), put its pin and build script in `gx/<name>/` (`upstream.env`, `build.sh`; the helpers in `src/lib` are shared, reached as `COPY --from=lib`), add the name to `gx/components.tsv`, add a case for it to `.github/scripts/binaries_layout.py`, and remove `--allow-empty` from the assemble line. The OS side must learn the component first (reader first, see CLAUDE.md).
